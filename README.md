# The Hitchhiker's Guide to the Future

Every time you write in it, you bring your future closer.

This repository is the clean-build home for the platform:

- a private diary for each writer;
- a public newsletter/blog;
- a paid membership that grants access to that writer's private diary;
- a node passport, granted by a host membership, that lets a traveler create one node of their own;
- a curated founding cohort seeded through paid memberships and gifted invitations;
- an opt-in semantic network that lets eligible members search across participating nodes;
- custom domains for each writer.

The first public node is intended to be:

`guide.hitchhikersguidetothefuture.com`

This is a new build. Existing work is source material for a controlled backfill, not an implicit dependency.

## Current status

Design and launch-contract stage. The decisions live in `docs/platform-charter.md`.

## Non-negotiable boundary

A paid membership to one node does not silently grant access to another writer's private diary. Cross-network search is a separate, explicit capability. Each writer controls whether their private corpus is included, what can be returned, and whether their node participates at all.
